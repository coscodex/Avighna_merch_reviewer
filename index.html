Default fonts

"Impact" is a system font, not a downloadable web font, so exported files can only embed it if you upload the exact .ttf (most Windows machines have it at C:\Windows\Fonts\Impact.ttf; on Mac it's in Font Book). "Yatra One" is a real Google Font, so it embeds automatically.

Per-person font overrides

For anyone whose default shouldn't be Impact/Yatra One — e.g. your own entry. Match by exact Order ID or exact printed name (case-insensitive). Applies automatically the first time that entry loads.
